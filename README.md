# 🧟 좀비 타워 디펜스 게임

웹 기반 타워 디펜스 게임으로, 좀비 웨이브로부터 기지를 지키는 것이 목표입니다.

## 🎮 게임 개요

- **장르**: 타워 디펜스
- **목표**: 10개의 좀비 웨이브를 모두 막아내기
- **기술**: Vanilla JavaScript + HTML5 Canvas

## 🚀 실행 방법

1. 저장소 클론 또는 다운로드
2. `index.html` 파일을 웹 브라우저로 열기
3. 게임 시작!

```bash
# 로컬 서버로 실행 (권장)
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 🎯 게임 규칙

### 기본 시스템
- **시작 골드**: 150
- **시작 생명**: 20
- **총 웨이브**: 10

### 승리 조건
- 10개의 웨이브를 모두 클리어

### 패배 조건
- 생명력이 0이 되면 게임 오버

## 🗼 타워 종류

| 타워 | 비용 | 공격력 | 사거리 | 공격속도 | 특수 능력 |
|------|------|--------|--------|----------|-----------|
| 🔫 총잡이 | 100 | 20 | 3 | 0.5초 | - |
| 🎯 스나이퍼 | 200 | 80 | 6 | 2초 | 높은 데미지 |
| 🔥 화염 | 150 | 15 | 2 | 0.3초 | 범위 공격 |
| ❄️ 슬로우 | 120 | 5 | 3 | 1초 | 속도 50% 감소 |

### 타워 업그레이드
- 각 타워는 최대 **레벨 3**까지 업그레이드 가능
- 업그레이드 시:
  - 공격력 **+50%**
  - 사거리 **+1**
- 업그레이드 비용: 기본 비용 × 1.5
- 판매 가격: 총 투자 비용의 70%

## 🧟 좀비 종류

| 좀비 | 체력 | 속도 | 보상 |
|------|------|------|------|
| 🧟 일반 | 100 | 1.0 | 10 골드 |
| 🧟‍♂️ 빠른 | 50 | 2.0 | 15 골드 |
| 🧟‍♀️ 탱크 | 500 | 0.5 | 50 골드 |
| 👹 보스 | 2000 | 0.7 | 200 골드 |

### 웨이브 구성
- **기본 좀비**: 10 + (웨이브 × 2)
- **빠른 좀비**: 웨이브 번호만큼
- **탱크 좀비**: 웨이브 ÷ 3 (내림)
- **보스 좀비**: 5웨이브마다 1마리

## 🎮 조작법

### 마우스
- **좌클릭**: 타워 선택/배치, 기존 타워 선택
- **우클릭**: 선택 취소

### 키보드 단축키
- **Space**: 일시정지/재개
- **ESC**: 선택 취소
- **1-4**: 타워 빠른 선택
- **S**: 웨이브 시작
- **+/=**: 배속 변경

### UI 버튼
- **▶️ 웨이브 시작**: 다음 웨이브 시작
- **⏸️ 일시정지**: 게임 일시정지
- **⏩ 배속**: 1x → 2x → 3x 전환
- **🔄 재시작**: 게임 재시작

## 💡 게임 전략 팁

1. **초반 전략**
   - 경로의 굴곡 지점에 총잡이 타워 배치
   - 골드를 모아 스나이퍼 타워 구매

2. **중반 전략**
   - 화염 타워로 다수의 적 처리
   - 슬로우 타워로 적 속도 감소

3. **후반 전략**
   - 타워 업그레이드에 집중
   - 보스 좀비 대비 고화력 타워 배치

4. **배치 포인트**
   - 경로가 꺾이는 지점에 타워 배치 시 공격 시간 증가
   - 사거리가 겹치도록 배치하여 화력 집중

## 🔧 개발자 콘솔 명령

브라우저 개발자 도구 콘솔에서 사용 가능:

```javascript
// 골드 추가
game.state.gold += 1000;

// 생명력 추가
game.state.lives += 10;

// 웨이브 강제 시작
game.startWave();

// 게임 속도 변경
game.state.gameSpeed = 5;

// 게임 상태 확인
console.log(game.state);
```
